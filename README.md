# HTML Advanced — Techium Styleguide

A semantic HTML style guide for Techium. This page demonstrates common HTML elements and how they are structured in a web document.

## Contents

- Headings and paragraphs
- Ordered, unordered, and definition lists
- Horizontal rules and quotations
- Text formatting and address information
- Tables
- Expandable details
- HTML5 video and audio

## Getting Started

Clone the repository, then open the style guide HTML file in a web browser. No installation or build step is required.

## Notes

The video and audio files are hosted externally and require an internet connection. The page also references local favicon files.
